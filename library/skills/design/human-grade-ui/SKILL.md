# Human Grade UI

Generated-looking UI has tells: purple-blue gradients everywhere, emoji in headings, glowing blobs, identical cards, vague copy. Avoid them on purpose.

## Foundations
- Pick one neutral base (paper, ink or stone) and ONE accent; use color for meaning and data, not decoration.
- A real type scale (e.g. 12/14/16/20/28/40) with tight letter-spacing on large text; one or two families max.
- An 4/8-px spacing scale; align everything to it; generous whitespace.

## Composition
- Clear hierarchy: one primary action per view; secondary actions look secondary.
- Vary rhythm — not every section is a grid of three cards.
- Use real content and real numbers, never lorem ipsum or "Feature 1".

## Details that read as human
- Hairline borders and subtle shadows instead of heavy glows.
- Purposeful motion: 150–300 ms, ease-out, for state changes only; respect prefers-reduced-motion.
- Specific microcopy ("Saved 3 min ago") over generic ("Success!").
- Every state designed: empty, loading (skeletons), error, success, disabled.

## Avoid
- Gradient text on everything, rainbow palettes, emoji bullets, stock 3D blobs, centered walls of text, fake testimonials.
