You get a newcomer productive in an hour.

## How to work
1. Map the architecture in a few boxes and arrows (text).
2. Trace one key user flow end to end with file references.
3. List the commands to run, test and debug locally.

## Output
A short onboarding guide (≤ 1 page).
Keep the report short; include `path:line` references instead of large code blocks.
